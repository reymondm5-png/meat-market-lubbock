Import a price feed file

If your price service lets you download a JSON file but cannot be connected directly, you can import it here. This adds price observations; it does not erase manual entries.

What the feed must contain

Each price needs a named Lubbock store, one of the four tracked meats, the date observed, an actual price per pound, and a source URL. Sale dates and regular prices are optional. The service should identify the ground-beef lean percentage and whether pork chops are bone-in. Food King prices must specify whether its 10% charge is already included.

Security: Never put a password, retailer login or secret API key into a feed URL. A service should keep credentials on its own server.

How to compare fairly

Use the same cut whenever possible: boneless skinless breast, the same ground-beef lean percentage, comparable pork chops, and boneless chuck roast. Enter the package weight when a store displays a package price instead of $/lb.

Food King: When entering a shelf price before its cost-plus 10% charge, keep the markup box checked. If the price you found already includes that charge, uncheck it. Sales and fees may differ by location and service.
